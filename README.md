# Retail Sales Analysis using Microsoft Excel

## Project Overview
This project analyzes retail sales data using Microsoft Excel to identify sales trends, regional performance, and business insights.

## Tools Used
- Microsoft Excel
- PivotTables
- Charts and Data Visualization
- Data Analysis

## Key Performance Indicators (KPIs)

| KPI | Result |
|---|---:|
| Total Sales | ₹46,26,325 |
| Total Profit | ₹8,72,725 |
| Total Orders | 150 |
| Total Quantity | 688 |
| Profit Margin | 19% |

## Key Insights
- North region recorded the highest sales.
- South region recorded the lowest sales.
- Regional sales contribution was analyzed.
- Sales and profit performance were evaluated.

## Project Objective
To analyze retail sales performance and identify business opportunities through Excel-based data analysis.
